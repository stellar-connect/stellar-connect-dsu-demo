# STELLAR CONNECT · DSU AI 챌린지 시연판

신입생 세미나(770명 · 9개 분반 · 팀 10명) 수업용 커뮤니티와 교수용 **Spark AI 수업 인사이트**의 시연용 웹앱입니다.
**모든 사람·대화·데이터는 가상 데이터**이며, 각 방문자의 브라우저 안에서만 동작합니다. 실제 개인정보나 외부 데이터베이스를 쓰지 않습니다.

## 실행
```
npm start
```
- 의존성 설치가 필요 없습니다(Node.js 20 이상).
- `PORT`(기본 8000), `HOST`(기본 0.0.0.0)에서 열립니다.

## Spark AI (교내 LLM) 연결
환경변수로만 설정합니다. 키를 코드나 저장소에 넣지 마세요.

| 변수 | 설명 |
|---|---|
| `AX_LLM_BASE_URL` (또는 `OPENAI_BASE_URL`) | OpenAI 호환 LLM 주소 (예: `https://…/v1`) |
| `AX_LLM_API_KEY` (또는 `OPENAI_API_KEY`) | 프로젝트 키 |
| `AX_LLM_MODEL` | 모델 이름 (기본 `ax-local`) |

연결 확인: `/api/health` → `{"ok":true,"llm":true}`.
LLM이 없거나 실패하면 화면에 "자동 요약 · AI 미연결"로 표시하고 지표 기반 요약을 보여 줍니다.
AI에는 학생 이름 없이 팀 단위 지표만 전송합니다.

## 체험 방법
첫 화면에서 **[교수로 체험]** → 왼쪽 메뉴 **Spark AI**. 상단 **[데이터 초기화]**로 처음 상태로 돌아갑니다.
